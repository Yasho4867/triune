**Release Version:** `3.0.0`

## Overview

**Lucid Machines v3.0.0** ships our comprehensive, security-hardened, and empirically verified open-source deep learning platform (`lucid-machines`) built around **the Triune architecture by Lucid Machines** (`TriuneTransformer` / `TriuneModel` / `TriuneConfig`), the configuration and validated substrate for **Junkie** (our first flagship model to be trained), and the commercial-grade native desktop workbench **Polysom Studio**.

This release completes all five major pipeline requirements (**R1–R5**):
1. **R1 — Locked 4-Layer Naming Boundary & Backward Compatibility** (`Lucid Machines` company / `Triune` core neural architecture / `Junkie` first flagship model / `Polysom Studio` desktop workbench)
2. **R2 — Multi-Directional CentroidSteer Diagnosis, Upgrade & Controlled 5-Seed Research Validation**
3. **R3 — Core Package, Native C/AVX2/CUDA Engine, `.NET 10` Polysom Studio Build & Asset Preservation Guardrails**
4. **R4 — Defense-in-Depth Security Hardening & Regression Suite**
5. **R5 — Self-Contained Static Project Website (`website/`), Local Launch Kit (`launch_kit/`) & Distribution Packaging**

## 2. CentroidSteer Multi-Directional Upgrade & M1 Validation (`R2`)

### Root-Cause Diagnosis of Legacy Rank-1 CentroidSteer
We identified and resolved the root causes explaining why legacy rank-1 CentroidSteer had near-zero effect (`benchmarks/CENTROIDSTEER_UPGRADE_VALIDATION_REPORT.md`):
1. **Un-Deflated Krylov Subspace Absorption** (residual centroid survival dropped to `0.1248` vs. `1.0000` upgraded; border gradient energy jumped **`22.12x`** from `0.0139` to `0.3082`).
2. **Synthetic Hidden Centroid Mismatch (`w_2` / `e[2]`)**: Proxy `FastGELU(W1 @ c_e)` diverged from true post-activation $\mathbb{E}[\text{FastGELU}(W_1 x)]$ (`0.1437` rel L2 error).
3. **Non-Contrastive Raw Centroids Under Shared Residual Offset**: Off-diagonal inter-expert cosine collapsed from `0.5763` (raw) to `-0.3329` (contrastive $\Delta\mu_e = \mu_e - \bar{\mu}$).
4. **Stale `subspace_step` Bias-Correction Damping**: Lack of independent `steer_step` counter damped refreshed border updates to `0.4844` vs. `1.0000` (**`2.06x` recovery**).
5. **Rank-1 Bottleneck**: Single 1D direction lacked multi-directional subspace coverage ($k_c = 4$) and live out-of-core drift tracking.

### v3.0.0 Architectural Upgrades & M1 5-Seed Validation (`[42, 1337, 2026, 777, 1024]`)
- **True Post-SwiGLU Hidden Centroids (`last_hidden_centroids`)**: `MoE_FFN` captures true hidden activations (`[E, H]`), contrastive directions, and $k_c=4$ orthonormal subspace directions via two-pass modified Gram-Schmidt.
- **Centroid-Deflated Krylov & Stiefel Orthonormality**: Batched `sCholQR2` + sliced Householder fallback guarantees $\|Q^T Q - I\|_F < 10^{-4}$ with independent `steer_step` reset and border RMS regularization (`0.35`).
- **Suite 2 — Multi-Domain MoE Specialization (5 Seeds, RTX 5070)**:
  - **Val Loss**: **`1.1998 ± 0.0574`** (upgraded) vs. **`1.2311 ± 0.0486`** (`nosteer`), paired $t$-test **`p = 0.0446`** (`3.32` vs `3.43` PPL).
  - **Alignment Energy**: **`0.1769 ± 0.0203`** vs. **`0.0404 ± 0.0023`** (`legacy`) — **`4.38x` alignment energy** (**`p = 9.882e-5 < 1e-4`** vs. legacy, `p = 4.113e-5` vs. `nosteer`).
- **Suite 3 — Real FineWeb-Edu Language Modeling (5 Seeds, 75.8M Continuation)**:
  - **Val Loss / PPL**: **`4.5185 ± 0.0043` (`91.70` PPL)** vs. **`4.5250 ± 0.0061` (`92.30` PPL)** AdamW baseline — paired $t$-test **`p = 0.0068`** (`p = 0.0069` PPL) at **`0.109 B/p`** expert state (vs. **`4.000 B/p`** AdamW).
  - **90.79M Tier-2 Memory**: `3.78 MB` (`0.1118 B/p`) vs. `135.21 MB` FP32 AdamW (**98.4% reduction**).

## 4. Defense-in-Depth Security Hardening (`R4`)

- **Checkpoint Deserialization (`weights_only=True`)**: Enforced across `finetune.py`, `rescue_checkpoint.py`, `verify_triangular_qr_residuals.py`, and API loaders with CPU-first `map_location="cpu"`.
- **Strict Path Confinement**: All `/v1/models/load`, `/v1/checkpoints/load`, `/v1/datasets/*`, `/v1/models/export`, `/v1/finetune/*`, and DAG file nodes enforce `Path.resolve(strict=False).is_relative_to(...)` and reject `..`, UNC, and absolute path traversal.
- **Proxy-Aware Bearer Auth, CSRF & Security Headers**: Requests with `Forwarded`, `X-Forwarded-For`, or `X-Real-IP` headers (or non-loopback hosts) require a valid `LUCID_MACHINES_API_TOKEN` / `TRIUNE_API_TOKEN` bearer token; state-changing HTTP routes and `/ws/telemetry` validate `Origin`/`Host`; responses include `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`, and `Content-Security-Policy`.
- **SSRF & Package Install Guards**: Dataset stream URLs and module download URLs enforce `validate_http_url` SSRF checks; `/v1/modules/install` pip execution is gated behind a curated allowlist or `LUCID_MACHINES_ALLOW_PIP_INSTALL=1`.
- **Plugin Cryptography, Sandbox & Provider Hygiene**: External workspace plugins default to `trusted=False` (Ed25519 signature required); `PythonSandbox` enforces strict memory/job limits and gates `allow_writes`; vLLM bridge defaults to `trust_remote_code=False`; Google Gemini provider sends API keys exclusively via the `x-goog-api-key` HTTP header.
